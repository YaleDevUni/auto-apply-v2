## 세션 운영 프로토콜
1. 오케스트레이터(메인 세션)는 **이 파일 → 해당 마일스톤 카드 → 필요한 §A 절만** 읽는다. 소스 트리를 넓게 읽지 않는다.
2. 태스크 1개 = `spec-implementer` 서브에이전트 1회. 프롬프트는 **카드 ID 만** 넘긴다 (`"T0.1 을 수행하라"`).
3. 서브에이전트는 구현 + 테스트 + `make check` + 기능 단위 커밋까지 하고 **15줄 이하 보고**(커밋 해시, check 결과 요약, 범위 밖 발견사항)만 돌려준다.
4. 오케스트레이터는 보고를 받아 이 파일을 갱신하고 다음 카드로. 범위 밖 발견사항은 "열린 질문"이나 새 카드로.
5. 파일 범위가 겹치지 않는 카드만 병렬 실행하고, 그때는 `isolation: worktree`.
6. 마일스톤 시작 시 상세 카드를 먼저 쓰고(오케스트레이터), 사용자 결정이 필요한 건 "열린 질문"을 먼저 푼다.
